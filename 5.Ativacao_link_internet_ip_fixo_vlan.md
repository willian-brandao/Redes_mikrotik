# Ativar o link de internet com ip fixo com e sem vlan 

1. desativar o dhcp client
   ```bash
      /ip/dhcp-client/disable
   ```
3. desativar o pppoe client
   ```
     /interface/pppoe-client/disable
   ```

1. Rede: 200.10.3.0/30
2. Endereços disponíveis
    * 200.10.3.0 - endereço de rede
    * 200.10.3.1 - VIVO (Provedor)
    * 200.10.3.2 - Contabilidade Brasil
    * 200.10.3.3 - broadcast

3. IP Mascara de Sub-Rede - 200.10.3.2/30
    * Gateway - 200.10.3.1
    * DNS - 8.8.8.8, 1.1.1.1

## Configuração de IP fixo sem VLAN

1. Definição de uma interface WAN para roteador receber link

```bash
    /ip/address/add address=200.10.3.2/30 interface=ether1-link-vivo netnetwork=200.10.3.0
```
1.1 Validação (ping gateway)
```bash
   /tool/ping 200.10.3.1
```
*Obs: Nesse momento o roteador não se comunica com a internet, apenas com o gateway*

2. Criar uma rota default associada ao gateway para que o roteador se comunique com a internet
```bash
    /ip/route/add dst-address=0.0.0.0/0 gateway=200.10.3.1
```
2.1 Validação (ping rede externa)
```bash
   /tool/ping 8.8.8.8
```
*Obs: atualmente o roteador consegue pingar endereços IP, porém não resolve nomes de domínio.*

2.2 Configuração de DNS
```
   /ip/dns/set servers=8.8.8.8,1.1.1.1
```

## Configuração de IP fixo comm VLAN

VLAN = 200
1. Rede: 200.10.3.4/30
2. Endereços disponíveis
    * 200.10.3.4 - endereço de rede
    * 200.10.3.5 - VIVO (Provedor)
    * 200.10.3.6 - Contabilidade Brasil
    * 200.10.3.7 - broadcast

3. IP Mascara de Sub-Rede - 200.10.3.6/30
    * Gateway - 200.10.3.5
    * DNS - 8.8.8.8, 1.1.1.1

1. Redefinir o endereço de ip configurado anteriormente
   ```bash
      /ip/address/disable numbers=2
      #numbers -> número de id de interface
   ```
2. Redefinir a rota default definida anteriormente.
   ```bash
      /ip/route/disable numbers=1
      #numbers -> número de id de interface
   ```
3. Configurar vlan
   ```bash
      /interface/vlan/add name=ether1-vlan200-link-vivo vlan-id=200 interface=ether1-link-vivo
   ```
4. Configurar o endereço de IP
   ```
      /ip/address/add address=200.10.3.6 network=200.10.3.4 interface=ether1_vlan200-link-vivo
   ```
5. Configurar a rota default da rede
   ```
      /ip/route/add dst-address=0.0.0.0/0 gateway=200.10.3.5
   ```
6. Redefinir as configurações de NAT para que os equipamentos conectados ao roteador possam se comunicar com a WAN
