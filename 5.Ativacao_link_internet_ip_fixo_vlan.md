# Ativar o link de internet com ip fixo com e sem vlan 

1. desativar o dhcp client
   ```bash
      /ip/dhcp-client/disable
   ```
3. desativar o pppoe client
   ```
     /interface/pppoe-client/disable
   ```

1. Rede: 200.10.3.0/30
2. Endereços disponíveis
    * 200.10.3.0 - endereço de rede
    * 200.10.3.1 - VIVO (Provedor)
    * 200.10.3.2 - Contabilidade Brasil
    * 200.10.3.3 - broadcast

3. IP Mascara de Sub-Rede - 200.10.3.2/30
    * Gateway - 200.10.3.1
    * DNS - 8.8.8.8, 1.1.1.1

## Configuração de IP fixo sem VLAN

1. Definição de uma interface WAN para roteador receber link

```bash
    /ip/address/add address=200.10.3.2/30 interface=ether1-link-vivo netnetwork=200.10.3.0
```
1.1 Validação (ping gateway)
```bash
   /tool/ping 200.10.3.1
```
*Obs: Nesse momento o roteador não se comunica com a internet, apenas com o gateway*

2. Criar uma rota default associada ao gateway para que o roteador se comunique com a internet
```bash
    /ip/route/add dst-address=0.0.0.0/0 gateway=200.10.3.1
```
2.1 Validação (ping rede externa)
```bash
   /tool/ping 8.8.8.8
```
